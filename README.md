# Hoverline Apps

Website for Hoverline Apps, published with GitHub Pages: https://mortez28.github.io/hoverline/

| Page | What |
| --- | --- |
| `index.html` | Home: all apps |
| `kestrel-player.html` | Kestrel IPTV Player: features and screenshots |
| `privacy.html` | Kestrel IPTV Player privacy policy (linked from its Play listing; keep the URL) |
| `songbird-prompter.html` | Songbird Prompter: features, Free vs Premium |
| `songbird-privacy.html` | Songbird Prompter privacy policy (use this URL in Play Console and the app) |

Plain HTML and one `style.css`; no build step. Push to `main` and Pages updates.

When an app's features, Premium limits or data use change, update its page and
privacy policy here in the same pass (Songbird's source of truth is
`docs/privacy-policy.md` and `billing/Entitlements.kt` in mortez28/teleprompter).
